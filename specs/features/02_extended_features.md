# 機能仕様: 拡張プラットフォーム機能 (Extended Features)
**モジュール**: `extended_features`  
**ステータス**: `active`  
**最終更新日**: 2026-10-08  

---

## 1. 概要
ユーザーから提示された以下の7つの発展的機能を管理・定義する仕様書。
1. **多面的ランキング (Rankings)**: 「商品化希望数」「週間急上昇」「シニア発明」「主婦の知恵」等の多軸アワード・コンテスト
2. **直販ネットショップ機能 (Direct Shop / EC)**: 発明家自身が手作り品や小ロット製品を直接販売できる仕組み（カート・購入フロー）
3. **AI販促ツール自動生成 (Marketing Kit)**: 発明登録データから「チラシ（A4）」や「名刺」データをワンクリック自動生成・PDF印刷発注連携
4. **専門家マッチング (Experts Directory)**: 試作屋・町工場・弁理士・デザイナーが登録し、発明家から試作や特許出願の依頼を受けられるB2B/B2Cマーケット
5. **メールマガジン配信 (Newsletter)**: 登録ユーザー向け新着発明・急上昇ランキング・商品化成立ニュースの配信
6. **通知設定センター (Notification Center)**: 「欲しい」ボタンが押された時等の通知チャネル（メール/LINE/ブラウザ通知）と頻度設定
7. **SNS定期・ワンタップ自動投稿 (Social Auto-Sharing)**: X (Twitter) や LINE、Facebook へのワンクリック投稿および定時自動告知機能

---

## 2. 画面およびルーティング設計
- `/rankings`: 多面的ランキング・アワード特集画面（総合・急上昇・シニア部門・主婦アイデア賞）
- `/shop`: 発明品マーケットプレイス・直接販売一覧（手作り品・小ロット生産・購入手続きモーダル）
- `/mypage/tools/print-kit`: チラシ・名刺のAI自動プレビュー＆ダウンロード・提携ネット印刷（ラクスル等）連携
- `/experts`: 試作屋・町工場・弁理士の専門家一覧＆NDA付き相談受付モーダル
- `/mypage/settings/notifications`: 通知方法（メール/LINE/プッシュ）および内容（欲しい即時通知/企業打診/まとめ）カスタマイズ画面
- `/mypage/tools/sns-automation`: SNSワンタップ投稿（X/LINE）＆定期自動配信Botスケジュール画面
- フッター・トップページ: 公式メールマガジン登録フォーム（週1回・新着＆商品化速報）

## 3. 実装済み機能の詳細仕様

### 3.1 多面的ランキング (`/rankings`)
- **4大アワードタブ**:
  1. 「総合・商品化希望順」: 欲しい！獲得数順（大田区の旋盤オープナー、傘ピタッとキャップ等）
  2. 「週間急上昇」: 直近7日間の注目度急上昇
  3. 「シニア発明家部門」: 65歳以上の職人・シニア発明家の知恵
  4. 「主婦・日常アイデア賞」: キッチン・水回り・時短の工夫
- **UI特長**: 金・銀・銅の表彰台バッジ、ワンクリックでの詳細遷移と投票アクション。

### 3.2 ネットショップ直販機能 (`/shop`)
- **ターゲット**: 量産前の手作り品や、ガレージ・工房で作られた少数限定品を欲しい読者・コレクター。
- **UI特長**:
  - 「手作り・一点物」「小ロット生産」の絞り込みフィルター
  - 在庫数・発送目安日数・送料の明記
  - 2ステップ購入モーダル（配送先入力、発明家への応援メッセージ入力、完了画面）

### 3.3 AI販促ツール自動生成キット (`/mypage/tools/print-kit`)
- **ターゲット**: 展示会、地元のシニアクラブ、町内会、見本市で配りたい発明家。
- **フォーマット切替**:
  - `A4 販促チラシ`: キャッチコピー、発明品写真、特許番号、3大ポイント、QRコードを自動配置
  - `発明家名刺`: 代表作写真・肩書・プロフィールURL入り名刺
- **出力＆連携**:
  - リアルタイム紙面プレビュー
  - 家庭用プリンター印刷 / 高解像度PDF書き出し
  - 提携ネット印刷（100部 980円〜）へのワンクリック入稿・注文モーダル

### 3.4 専門家マッチングディレクトリ (`/experts`)
- **ターゲット**: ポンチ絵から形にしたい、特許を出願したい、金型用3Dデータが欲しい発明家。
- **専門家カテゴリ**: 町工場（旋盤・マシニング）、弁理士（特許出願・知財調査）、3D CADデザイナー、木工・板金職人。
- **UI特長**:
  - 実績件数・評価レーティング・費用目安の表示
  - プラットフォーム標準秘密保持規約（NDA）同意チェック付きの相談依頼フォーム

### 3.5 粒度別通知設定センター (`/mypage/settings/notifications`)
- **通知チャネル**: メール / LINE公式連携 / 画面プッシュ通知。
- **トリガーイベント**:
  - 「欲しい！」ボタンが押された時（即時通知 / 1日1回まとめ）
  - 応援コメント・質問がついた時
  - 企業からの商品化打診・ライセンス相談（最重要フラグ）
  - 週間サマリーレポート
  - 公式メールマガジン
- **テスト通知機能**: 「今すぐテスト通知を受け取ってみる」で即時バナー演出。

### 3.6 SNS簡単・定期自動ポスト (`/mypage/tools/sns-automation`)
- **ワンタップ投稿**: X (Twitter) 用の魅力的な文面とハッシュタグをAI自動生成、即時共有インテント起動。
- **定期自動ポストBot**: 毎週（火・金など）や月2回の指定時間（18:00等）に自動で作品を紹介するスケジュール設定。
- **プレビュー**: Xタイムライン風のカード表示（OGP画像付き）。

### 3.7 メールマガジン配信
- フッターに常設されたメルマガ登録フォームにより、訪問者がワンクリックで購読可能。
- 登録完了時のリアルタイムトースト表示。

## 4. サブエージェント提言に基づく高度ブラッシュアップ仕様 (Refinements)

### 4.1 直販ショップの法的保護とシニア決済最適化
- **特定商取引法の代行表記**: シニア発明家の自宅住所・電話番号の公開リスクを防ぐため、運営事務局（発明ドットコム）の連絡先を代行表示。
- **PL法（製造物責任）免責同意**: 「手作り試作品のため、量産工業製品と同等の安全保証・耐久試験は行われていない」旨の明示的な購入時同意チェック。
- **決済方法の選択肢**: クレジットカードに加え、「コンビニ前払い」「銀行振込」のUI選択肢を提供。
- **住所入力の自動化**: 郵便番号からの住所自動検索ボタンによる入力摩擦の最小化。

### 4.2 チラシ・名刺AI印刷キットのプリント最適化＆O2Oトラッキング
- **家庭用印刷の `@media print` 対応**: 印刷ダイアログ表示時にナビや設定枠を非表示にし、プレビュー面（A4または名刺）のみを用紙中央に全画面出力。
- **QRコードO2O流入トラッキング**: QRコードURLに `?src=flyer_print` パラメータを自動付与し、マイページで「チラシQRコード経由のアクセス数」を集計・表示。

### 4.3 弁理士法第75条（非弁提携）の完全遵守
- 弁理士紹介の成約成果報酬（マージン受領）を一切排除し、「月額認証パートナー制度（SaaS型固定費）」および無料相談枠として適法運用。

### 4.4 通知センターのおやすみ時間帯（夜間ミュート）
- 21:00〜翌朝8:00の通知を自動保留し、朝8:00にまとめて送信する「夜間おやすみモード」の追加。
