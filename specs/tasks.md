## 3. タスク追加・変更の運用ルール
1. **仕様変更時**:
   - 新しい要望が出たら、まず `specs/features/` 配下の該当仕様書、または新規機能仕様書を作成・更新する。
   - その後、この `specs/tasks.md` に作業タスクを登録する。
2. **作業完了時**:
   - チェックボックス `[x]` を付け、`npm run build` または `npm run lint` の検証結果を仕様書・タスクに同期する。
3. **取り下げ・方針転換時**:
   - タスクを削除するのではなく、取り消し線（`~~タスク名~~`）または `(Cancelled / Deprecated)` を付与して履歴を残す。
